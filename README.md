# 皮影戏 · 千年光影

一个介绍皮影戏历史与制作工艺的单页网页，含大量图片、动图与交互效果。

## 页面内容

- **历史长河** — 从汉武帝“李夫人”传说，到宋元明清的兴盛，再到列入人类非遗
- **制作工艺** — 选皮、制皮、画稿、镂刻、敷彩、缀结等主要工序
- **台前台后** — 幕布、灯、签手与乐队的表演现场
- **流派纷呈 / 经典剧目** — 各地皮影流派与《白蛇传》《西游记》等剧目
- **影人画廊** — 博物馆藏品细看（点击可放大）

## 打开方式

直接用浏览器打开 `皮影戏.html` 即可，无需任何依赖。
